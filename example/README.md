# dither_animals Example

This is a demonstration app showcasing the `dither_animals` package.

## Features Demonstrated

- **30 Built-in Animated Animals**: Owl, Elephant, Rabbit, Fish, Turtle, Cat, Penguin, Frog, Octopus, Bear, Lion, Tiger, Dog, Panda, Pig, Fox, Monkey, Duck, Sheep, Hedgehog, Sun, Cloud, Moon, Star, Ghost, Mushroom, Cactus, Robot, Rocket, and Cupcake.
- **Dot Styles**: Toggle between crisp square pixels and smooth round stipple dots.
- **Motion Modes**: Seamless infinite loop or one-shot entrance.
- **Resolution Control**: Change dither grid density from coarse 48x48 up to ultra-fine 128x128.
- **Interactive Poking**: Tap any animal card to trigger haptic feedback and an expanding shockwave ripple.
- **Animal Search**: Live filter animals by name or personality traits.

## Running the Example

From the root of the repository or from the `example/` folder:

```bash
cd example
flutter pub get
flutter run
```
